# Пять случайных встреч

Русскоязычная мобильная визуальная новелла о двух людях, которые знакомятся в кафе и встречаются снова. В локальной редакции content27 доступны десять глав. Третья встреча проходит под звёздами, четвёртая — за играми у Влада. Во втором сезоне герои снимают 12 кадров на одну плёнку. В восьмой обновлены ужин, пять стадий иллюстраций и открытка с выбранной начинкой.

## Локальный запуск

Нужны Node.js 22.12 или новее и npm.

```sh
npm ci
npm run dev
```

Адрес напечатает Vite, обычно `http://127.0.0.1:5173/`. Для проверки отдельных глав открыть `/?dev=1#/chapters` и выбрать «Тестовые сцены». Если тестовый прогресс устарел, запуск нужной главы создаёт синтетический префикс в отдельном сохранении.

## Прогресс и сохранения

Игра автоматически сохраняет текущую реплику, выборы, альбом, настройки и права доступа. Коды можно ввести заранее. Для обычного запуска следующей главы нужно завершить предыдущую. Пробный повтор хранится отдельно от основной истории.

Версия схемы — `schemaVersion: 1`, редакция контента — `contentVersion: 27`. При переходе с content25 или content26 сохраняются завершённые главы 1–7, их открытки, достижения, ответ на приглашение после пятой главы, настройки и открытые главы. Главы 8–10 проходят заново. Если активную сцену шестой или седьмой главы восстановить нельзя, игрок начинает эту главу сначала. Для content24 с завершённой пятой главой сохраняются главы 1–5. В более ранних редакциях сохраняются настройки и открытые главы.

## Telegram Mini App

Владелец может настроить кнопку игры в BotFather через `/setmenubutton`, указав адрес GitHub Pages. Mini App использует официальный Telegram WebApp и CloudStorage. При разных локальной и облачной копиях игра предлагает выбрать нужную. Обычный браузер и Telegram используют отдельные сохранения.

## Проверки и сборка

Для Markdown проверь изменённые ссылки и пути. Для сценария запусти целевой тест главы. Для интерфейса проверь изменённый экран на телефоне.

Повседневные проверки движка, сохранений и двух мобильных сценариев:

```sh
npm test
npm run build
npm run test:smoke
```

Перед первым браузерным запуском установи Chromium командой `npx playwright install chromium`. Smoke проверяет восстановление текущей реплики и сохранность основной истории после пробного повтора.

Расширенные проверки:

```sh
npm run lint
npm run test:all
npm run test:e2e
npm run test:offline
npm run test:dev
```

`test:all` запускает все проверки Vitest, включая полные комбинаторные прогоны глав. `test:e2e` открывает сборку из `dist/`, `test:dev` проверяет тестовые сцены разработчика, а `test:offline` запускает изолированные браузерные сценарии.

Исходники игры находятся в [src](src), публичные ресурсы — в [public/assets](public/assets), промпты и ссылки на исходники — в [описании происхождения ассетов](ASSET_CREDITS.md).
