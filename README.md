# Пять случайных встреч

Русскоязычная мобильная визуальная новелла о двух людях, которые знакомятся в кафе и встречаются снова. В локальной редакции на 23 ноября 2026 года доступны десять глав. Третья встреча проходит под звёздами, четвёртая — за играми у Влада. Во втором сезоне герои снимают 12 кадров на одну плёнку. В восьмой обновлены ужин, пять стадий иллюстраций и открытка с выбранной начинкой.

## Локальный запуск

Нужны Node.js 22.12 или новее и npm.

```sh
npm ci
npm run dev
```

Адрес напечатает Vite, обычно `http://127.0.0.1:5173/`. Для проверки отдельных глав открыть `/?dev=1#/chapters` и выбрать «Тестовые сцены». Если тестовый прогресс устарел, запуск нужной главы создаёт синтетический префикс в отдельном сохранении.

## Прогресс и сохранения

Игра автоматически сохраняет текущую реплику, выборы, альбом, настройки и права доступа. Коды можно ввести заранее. Для обычного запуска следующей главы нужно завершить предыдущую. Пробный повтор хранится отдельно от основной истории.

Текущая схема — `schemaVersion: 1`, контент — `contentVersion: 26`. При загрузке сохранения `content25` сохраняются главы 1–7, их открытки, достижения, ответ на приглашение после пятой, настройки и все открытые главы; главы 8–10 начинаются заново. При загрузке `content24` с завершённой пятой главой сохраняются главы 1–5. Для редакций до `content24` начинается новое прохождение с прежними настройками и доступом.

## Telegram Mini App

Владелец может настроить кнопку игры в BotFather через `/setmenubutton`, указав адрес GitHub Pages. Mini App использует официальный Telegram WebApp и CloudStorage. При разных локальной и облачной копиях игра предлагает выбрать нужную. Обычный браузер и Telegram используют отдельные сохранения.

## Проверки и сборка

Для обычной локальной правки выбирай ближайшую проверку. Для Markdown достаточно проверить изменённые ссылки и пути, для сценария — целевой тест главы, для интерфейса — короткий запуск затронутого экрана. Команды ниже пригодятся для расширенной проверки и выпуска.

```sh
npm run typecheck
npm run lint
npm run test:unit
npm run validate:content
npm run build
npx playwright install chromium
npm run test:smoke
npm run test:offline
npm run test:dev
```

`test:smoke` обслуживает production-сборку из `dist/`, поэтому сначала нужна сборка. `test:offline` проверяет игру в изолированном Chromium с тестовым прогрессом. `test:dev` проверяет локальные тестовые сцены. Скриншоты проверок сохраняются в `test-results/`.

Исходники игры находятся в [src](src), публичные ресурсы — в [public/assets](public/assets), промпты и ссылки на исходники — в [описании происхождения ассетов](ASSET_CREDITS.md).
