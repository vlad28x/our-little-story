## 1. Единая визуальная концепция

Современная иллюстрированная инди-новелла: взрослые chibi-персонажи на фоне уютного города, бумажная фактура, мягкая линия, ограниченное количество предметов. Основа узнаваемости — выразительный силуэт и сцена, а не россыпь эмодзи. Настроение обложки небольшого авторского комикса, а не детского приложения.

Персонаж: 3,5 головы, мягкие, но не младенческие черты. Фоны: слегка упрощённая перспектива, крупные световые пятна, нарисованные предметы. Контур тёмно-коричневый, не чёрный; толщина при экспорте персонажа 1024×1536 — около 5–7 px. Два уровня тени и один мягкий блик. Едва заметная бумажная текстура только в фоне, не на тексте/лице.

Декор сцены ограничен 2–3 живыми деталями: пар от чашки, движение хвоста, свет на стекле. Сердце допустимо как маленький мотив одного финала, не универсальная валюта. Геймпады и предметы нарисованы, системные эмодзи их не заменяют.

## 3. Мобильная композиция

Проектировать от 390×844 CSS px, проверять 320×568, 360×800, 430×932 и планшет. `min-height:100svh`, поддержать `100dvh` при наличии; отступы `env(safe-area-inset-*)`. Не фиксировать сцену жёстко в 844 px. На низком экране диалог прокручивается, персонаж уменьшается; варианты остаются доступны.

Диалоговая зона и иллюстрация — одна игровая сцена, не лендинг из карточек и секций. На десктопе контейнер до 960 px с более широким фоном, диалог до 640 px; по бокам приглушённая заливка. Не растягивать портрет персонажа до гигантского лица. Landscape: иллюстрация слева, текст справа при достаточной ширине, иначе вертикальная прокрутка. Запрет поворота не нужен.

Кнопки ≥48×48 px, между соседними целями ≥8 px. Вариант ответа занимает всю ширину, не 3 тесных колонки. Встроенный браузер Telegram не требует собственного SDK. Системная клавиатура появляется только при вводе кода/редактировании текста отправки, не на каждом сюжетном выборе.

| Карта | Пять иллюстрированных конвертов по вертикали | Доступна, идёт, пройдена, нужен код, ещё в разработке |
| Сцена | Фон, Влад, диалог | Загрузка арта, готово, выбор, меню |
| Мини-игра | Большие предметы, ясная задача, помощь/пропуск | Обучение, игра, пауза, результат |
| Карточка | Иллюстрация и короткая фраза | PNG готовится, готов, экспорт недоступен |
| Альбом | Карточки одинаковой ценности | Найденные варианты, силуэты секретов |
| Настройки | Компактный лист поверх сцены | Звук, текст, движение, резервная копия |
| Приглашение | Финальный разговор с Владом после открытки, реплики и пять ответов | Пять ответов всегда видны; реакция и необязательный черновик |
| Восстановление | Чёткий текст и сохранённый последний шаг | Восстановить копию / импорт / новый старт |

В загрузке арта показывать нейтральную заливку нужного размера; не серый человеческий силуэт как якобы готового героя. При ошибке ресурса дать «Повторить» и текстовый режим сцены. Текст и кнопки не должны исчезать вместе с картинкой.

## 5. Ассеты: форматы и соглашения

Имена: lowercase, дефисы, без пробелов. Логический ID не равен файловому пути; связка в `assetManifest.ts`. Пример `vlad.city.smile → characters/vlad/city-smile.webp`. Ключи фонов: `bg.cafe.entry`, `bg.cafe.window`, `bg.rain.awning`, `bg.rain.arcade`, `bg.vlad.livingroom`, `bg.river.night`, `bg.cafe.sunset`.

| Группа | Рабочий оригинал | Runtime-экспорт | Геометрия/цель размера |
|---|---|---|---|
| Влад | PNG с прозрачностью, 1024×1536 | WebP alpha, 768×1152 | ≤180 KB/поза, опора стоп (0.5,0.96), лицо в верхних 36% |
| Нина | PNG 1024×1536 | WebP alpha 640×960 | ≤140 KB/поза |
| Кот | PNG 768×768 | WebP alpha 384×384 | ≤60 KB/поза |
| Фон | PNG 1800×2400 | WebP 900×1200 + 1440×960 wide | ≤280 KB mobile, ≤350 KB wide |
| Предметы поля | PNG 512×512 | WebP alpha 256×256 | ≤30 KB, важный объект в центре |
| Интерфейс | Исходный SVG | SVG | 24×24 / 32×32 viewBox, ≤5 KB |
| Карточка | Композиция из готового арта | PNG через Canvas | 1080×1350, целевой <2 MB |
| Музыка | Лицензированный/созданный оригинал | MP3, 96–128 kbps | Петля 30–45 с, ≤700 KB |
| SFX | WAV | MP3 | ≤30 KB, длительность ≤0,8 с |

Размеры — бюджеты, при плохом качестве их пересматривают явно. Все фоны сохраняют центральную безопасную зону: важное действие в средних 65% ширины и верхних 65% высоты, низ оставлен под интерфейс. Персонажи размещаются отдельными слоями, не вшиваются в фон. Это сохраняет лицо и даёт менять эмоции без новой сцены.

У персонажа общий прозрачный холст, без обрезания волос/пальцев; одна точка опоры для всех эмоций одного костюма. Разница масштаба между позами ≤2%. Фоновая композиция для wide — отдельный кроп с просмотром, не слепое растяжение.

### Дополнение для главы 3: квартира и геймпады

Гостиная вечером: лампа с тёплым абажуром, диван с двумя свободными местами, сложенный плед, телевизор, низкий столик с напитками и вкусняшками. Игровой свет мягко подсвечивает лица, но не делает комнату тёмной. Реальная еда на столе отличается от виртуальных блюд кухни. Ящик с запасными батарейками находится в тумбе под телевизором, виден без отдельного фона. Интерьер вымышленный, без адресов, личных фотографий, реальных оконных видов и привязки к планировке автора.

| ID | Ассет и состояние | Использование |
|---|---|---|
| `bg.vlad.livingroom` | `backgrounds/vlad-livingroom.webp`, mobile + wide по общему стандарту | Вся бытовая сцена главы 3, отдельный кроп стола вместо нового фона |
| `prop.xbox.first` | Тёмный Xbox-геймпад, индикатор горит | Подготовленное место Влада |
| `prop.xbox.second.off` / `prop.xbox.second.on` | Светлый Xbox-геймпад, одинаковый силуэт и ракурс; выключенный/включённый индикатор | Кнопка включения, неудачная попытка, успешный запуск |

Диван, плед, напитки и вкусняшки входят в фон. Перемещаемые геймпады, батарейки, пульт и блюдце — отдельные слои. Формат предметов: WebP alpha 256×256, ≤30 KB, рабочий PNG 512×512. Xbox-геймпады узнаваемы по форме, асимметричным стикам и ABXY; без рекламной композиции. Положение кнопок одинаково во всех состояниях. Они — сюжетный реквизит; игрок управляет игрой с телефона, подключение настоящих геймпадов не нужно.

Использовать имеющиеся `vlad.casual.smile/awkward/thinking/neutral/laugh/surprised`, не добавлять костюм или отдельную эмоцию для каждой шутки. При неудачном включении — короткая смена smile→awkward и неподвижный тёмный индикатор; никаких искр и поломанного корпуса. После батареек индикатор плавно загорается за 180 мс, на телевизоре два значка игроков; reduced motion — статическое состояние. Разница также описана текстом, не только цветом. В главе 5 вернуть маленькую иллюстрацию двух включённых геймпадов на панели приглашения, переиспользовав эти ассеты.

## 7. Анимации и звук

| Событие | Длительность / приём | Reduced motion |
|---|---|---|
| Смена сцены | Crossfade 220 мс | Мгновенно/80 мс |
| Смена эмоции | Прозрачность 120 мс, холст неподвижен | Мгновенно |
| Появление панели | 160 мс, смещение ≤8 px | Только opacity |
| Сбор жетона | Scale 1→1.06→1, 180 мс | Статический checkmark |
| Удивление | Один наклон 2°, 180 мс | Смена выражения |
| Кот | Редкое моргание, цикл не чаще 6 с | Статичная поза |
| Звёзды/пар | Медленное opacity, не более 3 объектов | Статично |
| Карточка | 220 мс раскрытие конверта | Сразу открыта |

Не анимировать каждую букву, не трясти весь экран, не мигать ярко, не использовать параллакс от наклона телефона. Анимации не должны менять логику игры. CSS transforms/opacity, без зависимости Framer Motion. При потере видимости останавливаются игра и музыка.

Звук выключен по умолчанию. Первая явная кнопка включения создаёт/разблокирует аудио. Управление громкостью единое; SFX тише реплик воображаемого разговора. Реальной озвучки и копирования голоса автора нет. Любая задача выполнима без звука. Для кухни отдельная лёгкая петля, в звёздной главе спокойная; максимальное число одновременных SFX — 2.
