# Четвёртая глава — «Разговор под звёздами»

17 октября 2026. Продолжена существующая игра, без новой копии проекта и без публикации. Доступны главы 1–4, пятая ещё готовится.

## Как открыть

Локальная игра: http://127.0.0.1:5173/. Завершить первые три главы, открыть карту «Пять встреч», ввести отдельный код четвёртой из сообщения Влада. Свободной кнопки открытия нет, прямой URL не обходит условия. Код можно получить заранее; порядок прохождения сохраняется. Код владельца записан в локальной OWNER_CHAPTER_CODES.md, исключённой из Git и dist. Старый ZVEZDY не работает.

Если вкладка была открыта во время разработки, обновить её через Ctrl+F5 без очистки localStorage. Сервер должен оставаться запущенным. На другом компьютере: `npm ci`, затем `npm run dev` из корня проекта. Исходники в `src/`, production-сборка в `dist/`; команды и GitHub Pages — в README.md. Ничего не опубликовано.

## История и последствия

**30 узлов, 83 реплики.** Новая отдельная встреча на освещённой набережной со скамейкой и видом на реку. Вступление помнит название команды и поддержку/обещание реванша из третьей главы. Игровой вечер не превращается автоматически в ночную прогулку сразу после выхода из квартиры.

Выбор места на скамейке меняет композицию и отдельную сцену: рядом или с другого края. Влад спокойно принимает удобную героине дистанцию, не прикасается автоматически. Сохранённое `bench` подготовлено для композиции главы 5.

После созвездия Влад признаёт, что иногда так старается придумать программу, что забывает просто побыть. Три ответа имеют полноценные равноправные сцены:

- «Мне нравится быть с тобой» → romantic, тёплая взаимность без обязательства и автоматического поцелуя.
- «Мне хорошо дружить с тобой» → friendly, такое же спокойное принятие без разочарованного вздоха.
- «Давай без названий» → undecided, без срока на окончательное решение.

Затем герои пишут желания на деревянных жетонах. Своё желание игрок выбирает из двух тем, без ввода личного текста. «Больше маленьких приключений» даёт «Созвездие приключений»; «Больше спокойных вечеров» — «Созвездие передышки». Влад оставляет свой пока скрытый текст для конверта главы 5. Состояния четвёртой — **четыре поля**: bench, constellation, bond, wish. Ошибка старого проектного документа «пять полей» исправлена.

Полные реплики и переходы: [CHAPTER_04_SCRIPT.md](CHAPTER_04_SCRIPT.md). Тест автоматически сравнивает все 30 узлов и 83 реплики документа с ch04.ts.

## Интерактивное созвездие

Четыре подписанные звезды с целями 54×54 px, соединение в любом порядке. Есть отмена последней точки. После четырёх игрок отдельно выбирает название рисунка — кот, два геймпада или чайник. Порядок точек декоративный: игра не проверяет астрономию или сходство. Все 24 порядка допустимы.

«Выбрать готовый чайник» доступно всегда. Такой результат честно подписан «Выбрали готовую картинку», не выдаёт техническое достижение «Своё небо», но сохраняет весь сюжет и обе открытки. Свой рисунок открывает достижение. Созвездие возвращается отдельной микросценой и изображением на PNG-открытке.

Таймера, обязательного drag и штрафов нет. После обновления страницы сбрасываются только косметические точки незавершённого рисунка; выбранная дистанция и предыстория остаются. Подтверждённый результат повторно не применяется, двойное подтверждение защищено и UI, и expectedTurn.

## Сохранения и повтор

Envelope остаётся `schemaVersion:1`, версия контента повышена до **4**. Выпуски 1–3 проверяются в прежних границах, затем обновляется только contentVersion; курсор, ответы, результаты, альбом, настройки, права и пробный прогон не сбрасываются. При следующей записи предыдущий валидный JSON остаётся backup. Новая глава автоматически не открывается.

`ConstellationResult={kind:'constellation',outcome:'cat'|'controllers'|'teapot',usedPreset:boolean}`. Готовая картинка допустима только для teapot. CardRecord четвёртой сохраняет usedPreset и силуэт в variant. Каноническая открытка строится из канонических story **и results**, поэтому пробный повтор не заменяет её подпись, даже когда в альбоме обновился тот же ID.

Пробный повтор пополняет коллекцию без изменения основной истории. Переписывание с четвёртой сохраняет первые три; с третьей удаляет основную четвёртую. Альбом, достижения и права остаются. Все унаследованные решения проверяются на согласованность при импорте.
