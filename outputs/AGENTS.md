CloudSnapshot.needsRewrite обнаруживает старый payload; TelegramEntry не считает его уже синхронизированным и записывает компактную копию с проверкой head, даже без нового действия. Различия только в журнале не требуют выбора копии. Предыдущий сырой банк/backup сохраняется для восстановления до обычной следующей ротации. Тесты — legacySave.ts, save.test.ts, journal-removal-offline.spec.ts; старые отчёты о журнале исторические.

При отказе CloudStorage UI раскрывает «Почему не сохранилось?»: стадия и безопасный короткий код, без сырых ошибок/launch data/содержимого копий. Cloud callback timeout теперь 20 секунд. HASH_UNAVAILABLE не должен превращать валидную копию в damaged или разрешать её автоматическую замену. Владелец передал реальный DATA_TOO_LONG на записи части. Исправление: новые части ограничены 3000 UTF-8 байтами JSON-строки с учётом экранирования; getItems читает максимум 32 ключа за запрос. Старые 3500-unit банки продолжают читаться; head/version, хеш исходного JSON, ключи и сохранения прежние. Граница — 176 частей на банк (353 ключа с head). Нельзя возвращать разбиение по string.length или прежний верхний предел count по длине в UTF-16. Подробности — TELEGRAM_MINI_APP.md.

Три одобренные пасхалки реализованы в SceneEasterEggs и content/easterEggs.ts: кудри, Пончик, печенье дома. Это только UI, без engine commands, новых флагов, сохранений или CloudStorage. Не связывать поглаживание с cat-supervisor: прежний секрет выдаётся за кота в TokenSearch и завершение главы. Не включать пасхалки в мини-играх, на паузе, в обложке/результате/InvitationPanel или поверх ошибки загрузки арта. Тексты, доступность и границы — SCENE_EASTER_EGGS.md; четыре интеграционных теста входят в test:offline. cookieTaken принадлежит SceneStage, а не условно смонтированному SceneEasterEggs: кухня/пауза не должны возвращать третью печеньку. Уход с экрана истории/reload сбрасывает только косметику. Сценарии/версии сохранения прежние.
