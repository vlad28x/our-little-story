## Как посмотреть

Из корня: npm run dev. В этой среде npm доступен через node work/tooling/package/bin/npm-cli.js run dev. Локальный сервер: http://127.0.0.1:5173/ . Исходники src/, готовая сборка dist/.

Для быстрой проверки без изменения обычной истории: http://127.0.0.1:5173/?dev=1#/chapters → раскрыть «Тестовые сцены» → «Тест: начать шестую встречу». Кнопка создаёт синтетический префикс1–5 в **отдельном dev-save**, затем начинает6 обычными переходами. Не применять её к пользовательскому storage key. Dev-режим недоступен в production.

В обычном прохождении код6 вводится в прежнем верхнем поле на карте. Код записан в локальной, исключённой из Git памятке OWNER_CHAPTER_CODES.md; реальные коды не копировать в общедоступные документы. Открытие не запускает сцену автоматически.

## Приватность и совместимость

cloudRaw исключает privateNotes/localNoteRevision и прежний continuation; сюжет, искры, конверт и карта синхронизируются. На втором устройстве при saved без текста показано «Личная заметка осталась на другом устройстве». При явном выборе облачной версии местные слоты сохраняются, показ текста требует совпавшего attemptId. Черновик отдельный и локальный. Нет отправки текста автору.

Ручная JSON-копия содержит финальные личные ответы; экспорт предупреждает об этом. Импорт по-прежнему требует явной замены, 256KB предел сохранён. Протокол Telegram с двумя банками/3000-byte частями не менялся. Старый клиент не читает content6: нужно обновление страницы, без понижения или сброса копии.

Позднее редактирование заметки меняет только localNoteRevision: облачный payload/revision не меняются. Локальная запись проверяет обе ревизии, чтобы две вкладки не перезаписали личный текст молча. Ошибка записи оставляет черновик и прежнее предупреждение storage.
