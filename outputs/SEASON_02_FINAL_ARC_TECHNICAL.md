Остальные правила переписывания/очистки из ТЗ 7 расширяются по номеру главы, без тотального privateNotes={} при старте 9.

### Облако и перенос

cloudRaw сохраняет privateNotes, privateWords, localNoteRevision и заменяет только continuation на null. Подтверждённые тексты идут в CloudStorage; URL, логи, аналитика, статические бонусы и карточки их не получают. Черновики находятся вне envelope. c8Word=custom без текста допустим в старой копии, не ошибка сохранения.

preserveLocalNotes / preserveLocalPrivateData: удалённые тексты и deleted имеют приоритет, недостающие слоты заполняются из scoped device/валидной backup только при совпадении попытки и вопроса/custom-слова. Не терять word при сохранении notes или наоборот. Другие Telegram userId/браузерные профили не смешивать. Полный ручной JSON-экспорт содержит notes+word с существующим предупреждением; импорт после явного подтверждения заменяет всю локальную копию по прежнему правилу. Редактирование текста меняет localNoteRevision и синхронизируется; при расхождении копий выбор явный. Протокол chunk/bank Telegram не менять.

## 7. Доступность и художественный минимум

Сохранять крупные одобренные adviser-спрайты в сюжетных сценах. Кнопки/предметы≥48px, весь интерактив доступен без точного попадания, есть кнопочные дубли, keyboard/focus, reduced motion. В мини-играх/форме/паузе фоновые пасхалки отключены. Не переиспользовать story.bench4 для новой дистанции 9; выводить новую постановку из её result.

Три новых фона всего на этот пакет: kitchen-evening8, cinema-courtyard9, cafe-terrace10. Остальные одобренные home.living/cafe.sunset/river.evening и city/casual-персонажи переиспользуются. Текст всегда HTML поверх арта, без слова пользователя в растровом ассете.
