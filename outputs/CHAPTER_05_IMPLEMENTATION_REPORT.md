## Как открыть

Локальная игра: http://127.0.0.1:5173/. Завершить четвёртую главу, открыть «Пять встреч», внизу карты раскрыть ввод кода и ввести отдельный код пятой, полученный от Влада. Памятка владельца — OWNER_CHAPTER_CODES.md, исключена из Git и dist. Код можно ввести заранее; начать главу без пройденных1–4 нельзя. Прежний DALSHE не действует. Значения кодов задаются в src/content/chapters/manifest.ts. Это управление ритмом сюрприза на статическом сайте, не серверная защита.

После обновления старой вкладки выполнить Ctrl+F5 без очистки localStorage. Локальный сервер оставлен запущенным; он должен работать, пока читается игра. На другом компьютере: npm ci, затем npm run dev из корня проекта. Исходники — src/, production-сборка — dist/. README содержит остальные команды и настройку GitHub Pages.

## Что реализовано

**32 узла и 83 реплики** в ch05.ts; полный точный сценарий и все переходы — [CHAPTER_05_SCRIPT.md](CHAPTER_05_SCRIPT.md). Героев встречает знакомое кафе на закате, Влад немного нарядился в чёрный пиджак и водолазку. Нина помнит дождливый маршрут, предмет из второй главы появляется на столе, Пончик возвращается по отдельной сцене wait/help. Первое знакомство вспоминается согласно approach. Дистанция bench сохраняется в композиции.

Интерактивный альбом: три жетона — знакомство, игровой вечер, набережная. Тап жетона и свободного места раскладывает воспоминание и открывает три реплики; повторный тап позволяет перечитать. Порядок свободный. «Положить вместе» доступно всегда. Таймера, перетаскивания и штрафов нет. Воспоминания читают текущую story: план и поиск, результат кухни и название команды, стиль игры, созвездие и желание. Варианты из коллекции других прохождений не подмешиваются.

В конверте открывается желание Влада: «чтобы после пятой встречи нашёлся повод для шестой». Затем четыре равноправных явных финала:

- Романтический — «Место для шестой встречи».
- Комический — «Продлено котом».
- Игровой — «Второй игрок остаётся», с названием команды и возвратом team/rematch.
- Дружеский — «Хорошо, что встретились».

Все доступны при любом bond. После прежней дружбы романтическая кнопка прямо выражает новый выбор: «Кажется, сейчас я хочу попробовать свидание». Автоматического поцелуя или обязательства нет. Каждый финал даёт открытку и общее достижение «Пять встреч» без дублей. В коллекции всей игры 12 разных карточек и пять достижений.

## Добровольное продолжение

После канонического результата пятой находится отдельная закрытая панель. В ней три строки о двух геймпадах, которые Влад теперь проверил, и одна короткая отсылка по controllerReaction. Шутка не повторяется в жетоне кухни и четырёх финалах.

Четыре одинаково доступных варианта: игровой вечер, прогулка/кафе, переписка, «Не сейчас». Выбор по умолчанию отсутствует. Закрытие панели ничего не записывает. Выбор continuation хранится только на устройстве; экран прямо объясняет, что Влад его не увидит без самостоятельной отправки.

Для первых трёх вариантов есть редактируемый черновик. Текст не попадает в JSON или PNG и исчезает после закрытия страницы. Копирование и системная отправка запускаются отдельными кнопками, адресата выбирает игрок. Для «Не сейчас» черновика и отправки нет. При недоступном Clipboard/Share можно выделить текст вручную; отмена системного меню не считается доставкой. Раскрываемая реплика о такси ничего не бронирует. Контакт Влада не придуман, Telegram SDK и backend не добавлены.

В пробном повторе, во время активного trial и при просмотре открытки из альбома реальное приглашение не показывается. Можно вернуться к основному результату пятой с карты глав.

## Сохранения и повтор

Envelope schemaVersion остаётся1, contentVersion повышен до5. Старые версии1–4 проверяются в прежних границах, затем меняется номер контента. Ключи Storage прежние, курсор, выборы, настройки, альбом, права и trial не сбрасываются. Предыдущий валидный JSON остаётся backup при следующей записи.

MemoriesResult = {kind:'memories',outcome:'viewed'|'skipped'}, без нового story-поля. Результат обязателен после альбома и в записи завершённой пятой. Незавершённая расстановка после reload начинается заново; уже подтверждённый результат не повторяется. Двойное завершение защищено expectedTurn и локальной защёлкой.

Trial пополняет альбом и не меняет canonical/continuation. «Изменить мою историю» с пятой сохраняет1–4 и удаляет её основной финал; изменение более ранней главы удаляет соответствующий суффикс. Continuation сбрасывается при переписывании основной истории. Права, альбом и достижения остаются. Импорт ненулевого continuation без завершённой основной пятой отклоняется.
