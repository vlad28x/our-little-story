## 2. Мини-игра «Десерт на двоих»

Это украшение готового десерта, не повтор кухни 3. Без таймера, drag-and-drop, неправильных ответов и скрытой оценки.

```ts
type DessertTopping = 'berry' | 'chocolate' | 'honey';
type DessertMark = 'star' | 'heart' | 'swirl';
type DessertDraft = {
  kind: 'dessert'; topping: DessertTopping | null; mark: DessertMark | null;
};
type DessertAction =
  | {kind: 'set-topping'; value: DessertTopping}
  | {kind: 'set-mark'; value: DessertMark}
  | {kind: 'reset'};
type DessertResult =
  | {kind: 'dessert'; mode: 'completed'; topping: DessertTopping; mark: DessertMark}
  | {kind: 'dessert'; mode: 'shared'; topping: 'berry'; mark: 'star'}
  | {kind: 'dessert'; mode: 'skipped'; topping: null; mark: null};
```

Это payload-модель; внешний GameCommand сохраняет expectedTurn/chapter/node и действующие проверки reducer. Результат в results['dessert']; черновик в activity. Чистый dessertModel обрабатывает настройку и возвращает новый draft, без random/time/storage.

UI: превью десерта, группы «Добавим сверху» (Ягоды/Шоколад/Мёд) и «Маленькая деталь» (Звезда/Сердечко/Завиток). Выделение видно без цвета: рамка и галочка. «Готово» доступно при двух выбранных значениях; результат completed должен совпадать с draft. Всего 9 собственных комбинаций. «Давай вместе» принимает shared ягод+звезды; «Оставить десерт как есть» принимает skipped. Итого 11 результатов.

Снизу короткое пояснение: «Совместный вариант или пропуск заменит неподтверждённое украшение». Это явное действие; ни один тап по декору сам игру не завершает. До подтверждения можно менять детали и очищать preview; reload восстанавливает их. Shared/skipped принимаются из любого draft и нормализуют значения строго как выше. После end повторный game-result — no-op. Контрольные точки только изменения модели/подтверждение, не кадры анимации.

## 3. Общее слово и личный ответ

`c8.word` — обычный choice: «Ещё минутку»=minute, «Без спешки»=slow, «Такс»=taks, своё слово, без названия=none. Custom ведёт в новый ограниченный label-node `c8.word.custom`, не выставляя c8Word заранее.

LabelId=s2.word8; максимум 24 Unicode code points, нормализация и локальные слоты privateWords по общему контракту. Поле не является ответом на интимный вопрос; это подпись на ярлычке. Пустая/слишком длинная строка не проходит «Назвать так»; «Без названия» всегда доступно. Никакого автоматического усечения, HTML, подстановки в реплику Влада или публикации текста. Набранное переживает reload только в локальном draft.

При saved атомарно: текст в privateWords нужной попытки + c8Word=custom + voice + переход. При skipped: c8Word=none + voice + очистка лишь черновика/слота текущей попытки. Готовые слова не пишутся как приватный текст; renderer берёт локализованный литерал. Без custom-текста после переноса из Telegram — нейтральный ярлычок «Наше слово», при none ярлычка нет. Кнопки изменения/удаления своей подписи только в соответствующем результате 8; удаление не меняет сюжетный choice и не обнуляет искру.

Ровно один note-node: s2.q8 «Как бы ты дала мне понять, что хочешь поцелуя?». До 280 code points; можно пропустить. Действующий PersonalNote расширяется по карте глав, не создаётся второй журнал. Личный ответ никогда не вызывает поцелуй и не читается Владом. Settings/backup честно сообщают, что полный JSON содержит личные записи и своё слово; CloudStorage также сохраняет подтверждённые записи и своё слово.
