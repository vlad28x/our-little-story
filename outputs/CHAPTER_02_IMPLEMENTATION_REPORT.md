## Как открыть

Игра: http://127.0.0.1:5173/. Локальный сервер должен оставаться запущенным. После завершения первой главы перейти на карту «Пять встреч», ввести код, лично присланный автором, затем «Начать встречу». Прямая ссылка не обходит прохождение первой главы.

На другом компьютере: из корня проекта выполнить `npm ci`, затем `npm run dev`. Исходники — в `src/`, готовая production-сборка — в `dist/`; её нужно обслуживать через HTTP. Подробности запуска и настройки GitHub Pages — в корневом README.md.

## Старые сохранения

`schemaVersion` остаётся 1, `contentVersion` повышена до 2. Старый формат сначала проходит проверку в прежних границах, затем обновляется в памяти без изменения курсора, выбранных ответов, карточек, настроек и прав. Следующее игровое действие сохраняет новую версию; предыдущий валидный JSON сохраняется как резервная копия. Основной ключ localStorage прежний.

Незавершённый пазл после обновления страницы начинается заново с сохранённой сцены. Уже подтверждённый исход повторно не применяется. Сюжетные решения не зависят от таймеров анимации. JSON-импорт проверяет последовательность глав и согласованность унаследованных решений.

## Проверки

- TypeScript strict и ESLint — успешно.
- **40 тестов** игровой логики, графов, сценариев и сохранений — успешно. Внутри проверены **432 сочетания** памяти первой главы и решений второй; оба финала и все исходы пазла достижимы.
- **13 браузерных тестов** production-версии — успешно для корня сайта и отдельно для `/preview-test/`, соответствующего подпапке GitHub Pages. Покрыты обе главы, сохранения, импорт/экспорт, повтор, открытие второй главы, пазл, загрузка арта и защита недоступных маршрутов.
- Дополнительный визуальный проход на локальном сервере: мобильные экраны, прохождение обеих глав, сохранённые результаты `[1,2]`, PNG-открытка; ошибок страницы и горизонтального переполнения не обнаружено.
- Финальная production-сборка оставлена с корневым base `/`. Для GitHub Pages используется существующий workflow и заданный владельцем `VITE_BASE_PATH`.

Проверка мобильности выполнена в Chromium с эмуляцией Pixel 7 и экрана 320×568. Реальные Safari iPhone, Telegram и системная отправка на телефоне требуют проверки на устройстве. Читательский темп 5–7 минут пока не измерялся на человеческом плейтесте.
