## 2. Мини-игра «Устроимся?»

Это небольшая сцена с тремя осмысленными настройками. Все 12 собственных комбинаций допустимы, нет правильного ответа.

```ts
type MovieSeat = 'near' | 'space';
type MovieLight = 'warm' | 'dim';
type MovieDrink = 'tea' | 'cocoa' | 'water';
type MovieSetupDraft = {
  kind: 'movie-setup'; seat: MovieSeat | null;
  light: MovieLight | null; drink: MovieDrink | null;
};
type MovieSetupAction =
  | {kind: 'set-seat'; value: MovieSeat}
  | {kind: 'set-light'; value: MovieLight}
  | {kind: 'set-drink'; value: MovieDrink}
  | {kind: 'reset'};
type MovieSetupResult =
  | {kind: 'movie-setup'; mode: 'completed'; seat: MovieSeat; light: MovieLight; drink: MovieDrink}
  | {kind: 'movie-setup'; mode: 'shared'; seat: 'space'; light: 'warm'; drink: 'tea'}
  | {kind: 'movie-setup'; mode: 'skipped'; seat: null; light: null; drink: null};
```

Внешняя команда содержит expectedTurn и текущий node. Чистый movieSetupModel хранит draft в activity, итог в results['movie-setup']. Partial completed и результат, не совпавший с draft, запрещены. Shared/skipped разрешены из любого неподтверждённого состояния с явным пояснением замены preview. В skipped renderer показывает нейтральные space/warm/tea, но не выдаёт scene-искру. Всего 14 форм результата:12completed,1shared,1skipped.

Три группы крупных кнопок:

- «Где устроимся?» — «Рядом» / «Чуть больше пространства». Рядом означает расположение, без автоматического касания.
- «Какой свет?» — «Тёплый» / «Приглушённый». Это собственная настольная лампа/фонарь у их места, не управление всем кинодвориком.
- «Что взять?» — «Чай» / «Какао» / «Вода».

Тап по месту/лампе/чашке в иллюстрации только переводит фокус и прокручивает к группе; не принимает скрытый вариант. Те же действия полностью доступны обычными кнопками. «Готово» подтверждает заполненные 3 группы; «Давай как ты подготовил» принимает shared; «Продолжить без настройки» — skipped. Draft переживает паузу/reload, accepted result не переигрывается при рендере. На маленьком экране сцена и группы идут вертикально; не раскладывать 12 вариантов сеткой.

Настройки видны в последующих сценах. Открытка хранит место и фиксированный мотив, не настройки фильма. Выбор c9Ending=hug явно разрешает приблизиться для выбранного объятия. Это постановка финального действия, не заднее изменение results.seat. Warm/dim не влияет на доступность поцелуя.
