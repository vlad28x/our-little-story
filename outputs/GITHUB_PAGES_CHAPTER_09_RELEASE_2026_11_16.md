# Выпуск девятой главы · 16 ноября 2026

Прямое поручение владельца: «Опубликуй и проверь сайт», включая коммит и отправку изменений в GitHub.

## Состав

Новая девятая «С крышей разберёмся» по утверждённому исправленному сценарию, её фоны и векторные фазы фильма, сохранения schema1/content18, обычный доступ после восьмой и прежнего кода, пробный повтор, альбом и изолированный dev-просмотр. Десятая остаётся закрытой.

В выпуск включён исправленный `courtyard9-open-v2.webp`: передний ряд стульев читается 1–9 без пропуска семёрки. Активный manifest использует новую версию; прежняя картинка оставлена как исходная редакция.

Content17 обновляется без сброса первых восьми глав, текущих курсоров, решений, открыток, настроек, реальных ответов и прав открытия. Старые миграции не расширяются новым сбросом шестой. SHA-256 исходников глав1–8 и10 совпадает с локальным снимком до реализации. Реальные пользовательские обычные и Telegram-данные не используются.

Посторонние сценарные исследования, передача аккаунта, личные материалы, локальные снимки и временные инструменты в коммит не включаются. Включены только относящиеся к девятой исходники, проверки, четыре сценарных/отчётных документа и этот отчёт выпуска.

## Проверка выпуска

Проверки выполняются по точному архиву release-коммита, отдельно от изменяемой рабочей папки. Сборка использует base `/our-little-story/`. Результат полного набора, GitHub Actions, опубликованные хеши и проверки публичного сайта будут записаны после завершения.
