## Как открыть

`npm run dev` → http://127.0.0.1:5173/?dev=1#/chapters → «Тестовые сцены» → «Тест: начать седьмую встречу». Синтетический префикс только в отдельном dev-save. Обычный путь: завершить1–6, ввести личный код7 и нажать начало встречи на карте. Код записан в manifest и игнорируемой OWNER_CHAPTER_CODES.md, сообщается владельцу отдельно.

Исходники — src/, локальная production-сборка — dist/. После Pages-проверок оставлена свежая root-base сборка для локального preview; dev-сервер5173 остаётся запущенным. Публиковать только после нового прямого поручения автора.
