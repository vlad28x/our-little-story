## Личные ответы и интерфейс

По одному личному вопросу в каждой главе. Два готовых ответа и третий «Своими словами», без предвыбора. Карточка только выделяется; отдельная кнопка подтверждает сохранение. «Пропустить» остаётся доступно. Своё поле сохраняется при переключении вариантов и reload, поддерживает редактирование пресета.280 Unicode code points; превышение видно, текст не обрезается молча. Enter не отправляет ответ, Ctrl/Cmd+Enter — явное подтверждение. Поле прокручивается при открытии клавиатуры/изменении visual viewport.

После подтверждения заметки checkpoint записывается сразу, а кнопки следующей сцены на300мс защищены от второго тапа того же двойного нажатия. Это не задержка сохранения/таймер сюжета. Найденный при финальной браузерной проверке случай случайного выбора следующего ответа исправлен; фокус кнопки «Дальше» восстанавливается после защиты.

Сохранённые готовые и свои ответы по-прежнему входят в privateNotes, JSON и Telegram CloudStorage. Draft format4 остаётся на устройстве и читает прежние форматы. Удаление/изменение синхронизируются прежними localNoteRevision/CAS; чужие попытки и аккаунты не объединяются. Текст не интерпретируется как команда/сюжетный выбор и не отправляется владельцу. Удалённая ранее подпись о хранении только на устройстве не возвращалась.

Советчики показываются по одному крупным портретом у края, основной Влад остаётся видимым. Их текст читается в обычной панели без таймера. В10 после ухода они не возвращаются в личную сцену, ночь и утро. Утренний фон и открытка c10.overnight готовы: [ассет, промпт и происхождение](SEASON_02_R2_ART.md). Новый backend, музыка и журнал не добавлялись.

## Сохранения и обновление

Runtime schema1/content11; число глав отдельно ограничено10. Run/ChapterRecord6–10 имеют scriptRevision2. Условные поля c7Reply/c8Hoodie/c9Hoodie и финальные поля10 появляются только по своему действию, не требуются во всех ветках.

Проверка повторяет настоящий граф и действия. Для мини-игр используется конечный автомат допустимых состояний и точное число шагов, включая reset/backtracking, без линейного перебора миллиона поддельных turns. Пересмотр c10Intent и переход c10Venue не отбрасываются преждевременно; итоговое состояние всё равно должно полностью совпасть с достижимым checkpoint/end.

До замены сохранён отдельный read-only R1-парсер и7 синтетических golden snapshots. В архиве src/legacy/r1 опущены только отображаемые тексты строк для уменьшения загрузки; узлы, длины диалогов, условия/эффекты и переходы прежние. Архив не используется для живой игры. Исторические сценарии R1 сохранены и помечены.

Старая копия только с первыми5 мигрирует без сброса. Копия с R1 вторым сезоном открывает экран «Сезон обновился», экспорт исходника и явный перезапуск сезона; первые5 доступны для просмотра. До подтверждения нет записи и облачной синхронизации. После подтверждения raw остаётся в scoped `:legacy-r1`, права открытия и первые5 сохраняются, стартует новая6. Если исходник нельзя сохранить на устройстве, замена блокируется с объяснением.

Защита действует и в GameProvider, и в низкоуровневых persist/TelegramCloud.write: неподтверждённый legacy-preview писать нельзя. Две разные R1-копии с одинаковыми первыми5 не считаются одинаковыми — показывается выбор исходников. Telegram использует прежний проверенный head/CAS, части/UTF-8/SHA-256/read-back и запись head последней. Реальные данные пользователя в локальном браузере и Telegram при разработке не трогались.

В dev сохранены прямые явные запуски6–10 и выход к обычной игре; префиксы создаются новым reducer и проходят parseSave. Повреждённый тест не требует очищать весь localStorage. Открыть: `http://127.0.0.1:5173/?dev=1#/chapters` → «Тестовые сцены». При старом dev-save — соответствующая кнопка на экране восстановления.
