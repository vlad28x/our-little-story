## Архитектура и сохранения

SchemaVersion1 сохранена; актуальный contentVersion10. Источники 1–9 строго проверяются по собственным границам до миграции: права, курсоры, records, startStates, даты/ревизии истории не сбрасываются. Отдельные коды 8/9/10 зарегистрированы в прежнем manifest; ввод заранее сохраняет право, префикс всё равно обязателен. Старые коды не менялись.

Общий resolveScene выбирает первую совпавшую Scene.variant. Валидатор контента проверяет все основные/альтернативные asset ID; SceneStage получает правильную семью персонажа и подпись локации. Для карточек 8–10 добавлен venue, производный от record.story. Текущий результат берёт campaign/trial episodeRecord, а не последнюю коллекционную карточку такого же ID. Альбом хранит последний найденный экземпляр; канон при trial не переписывается.

Episode registry теперь 6–10 со своими question/note/guide/spark/bonus/card ID. Каждый run имеет отдельные attemptId и 0/3. Игровые действия/результаты идут через reducer/step и expectedTurn. Новая reachableFinalArc воспроизводит authored choices/настоящие команды с лимитом 600 посещений, сверяет этап, историю, activity, результаты и искры. Для preview учитываются дополнительные законные действия; до входа в игру произвольный turn не допускается, начальный пустой preview с невозможным одним лишним действием отклоняется. Старые правила 6/7 не ослаблены.

PrivateNotes — карта 6–10, по campaign/trial слоту; максимум 10 конечных текстов до 280Unicode code points. PrivateWords — два слота слова 8, до 24code points. label-node и label-result передают в engine только статус, текст атомарно записывается state-action отдельно. В story/results/card/bonus текст не дублируется. Редактирование/удаление слова меняет только localNoteRevision, не историю/облачную revision. Короткая подпись может быть готовой/своей/отсутствовать; это не второй личный вопрос.

Черновики format3: максимум два target-слота note/word, с chapter/questionId/labelId/attemptId. Format2 и старый draft6 читаются без потери валидного соответствующего ввода. Подтверждение/отмена чистит свой слот. Ввод 25emoji не обрезается молча; подтверждение блокируется, до 24 можно сохранить. React экранирует HTML как текст.

CloudRaw содержит privateNotes={}, privateWords={}, localNoteRevision=0 и continuation=null. Сюжет/искры/results передаются прежними bounded parts/banks, протокол не менялся. При выборе облака сохраняются обе локальные структуры scoped device/backup; разные пользователи/обычный браузер не смешиваются. Без custom-текста законен нейтральный ярлык «Наше слово» и пояснение о другом устройстве. Ручной JSON содержит личные записи/слово с предупреждением. Canonical9/10 и их trial берут подпись только canonical8, не последней trial8.
