# Третья глава — «Игровой вечер»

Теперь реализована и четвёртая глава. Актуальный срез и проверки — [CHAPTER_04_IMPLEMENTATION_REPORT.md](CHAPTER_04_IMPLEMENTATION_REPORT.md); сведения о недоступной четвёртой ниже относятся к предыдущему этапу.

## Исправление пустого экрана после выпуска

Пользователь сообщил точную ошибку `Unknown asset vlad.casual.smile` на локальном сервере. Домашние и городские спрайты теперь зарегистрированы явно в неизменяемом manifest, без последующего заполнения циклами. Добавлена отдельная проверка разрешения всех домашних эмоций и файлов, а также отрисовка всех сюжетных сцен третьей главы в тесте React. Новые обработчики ошибок отрисовки и загрузки модулей показывают текст ошибки и предлагают обновление страницы без удаления сохранения, вместо пустого экрана.

После исправления прошли TypeScript, ESLint, 55 тестов и production-сборка. Повторная интерактивная проверка в пользовательском браузере была недоступна из-за отказа доступа к локальной вкладке; старые 17 браузерных проверок ниже относятся к предыдущему этапу. Для уже открытой вкладки нужен Ctrl+F5. Механизм устаревания manifest в конкретной вкладке не воспроизведён; подтверждённый симптом — отсутствующий ресурс по указанному ключу.

17 октября 2026. Реализована в существующем React + TypeScript + Vite проекте. Первые две главы сохранены. Главы 4–5 ещё недоступны; сайт не опубликован.

## Как открыть

Локальная игра: http://127.0.0.1:5173/. На карте «Пять встреч» третья глава ждёт личного кода от Влада. Понадобятся финалы первых двух глав и отдельный код третьей. Свободного открытия нет; прямой URL не обходит условия. Код и инструкция владельца — в локальной памятке OWNER_CHAPTER_CODES.md, исключённой из Git и dist. В интерфейсе код не подсказывается.

Другой компьютер: из корня проекта `npm ci`, затем `npm run dev`. Исходники находятся в `src/`, production-сборка — в `dist/`. Локальный сервер нужно оставлять запущенным во время игры. Подготовка GitHub Pages по-прежнему описана в README.md; публикация требует отдельного поручения.

## История

**33 узла, 78 реплик.** Вечер у Влада: диван, плед, мягкий свет, телевизор, два Xbox-геймпада, напитки и заранее приготовленные вкусняшки. `eveningMood` второй главы меняет вступление.

Сохранены утверждённые реплики «такс, всё готово…», «так», «кажется, я подготовил полтора геймпада». Игрок сам нажимает кнопку второго геймпада. Три реакции — подкол, помощь, смешное предложение — дают отдельные сцены. Запасные батарейки быстро решают проблему, без поиска по квартире и повторной поломки. Выбор возвращается перед обучением, а в absurd на паузах остаётся пульт на блюдце для «запасных». `controllerReaction` сохранён для будущего возвращения в главе 5.

Три названия команды появляются в игре и открытке. Две стратегии меняют время подготовки напарника. Четыре исхода кухни меняют сцену виртуального ужина и подпись одной открытки «Ужин по обстоятельствам». Настоящие вкусняшки есть всегда. После игры — поддержка или обещание реванша; `gameAftercare` подготовлен для вступления главы 4. Никаких очков любви или штрафов за пропуск.

Полный текст и переходы: [CHAPTER_03_SCRIPT.md](CHAPTER_03_SCRIPT.md). Реплики и узлы документа сверяются с реализованным контентом автоматически.

## Мини-игра

«Кухня на двоих» — оригинальная небольшая игра на DOM-кнопках и SVG, а не ролик. Игрок выбирает заказ, добавляет первый ингредиент, передаёт Владу, затем подаёт готовое блюдо. Две независимые тарелки; третий заказ появляется после первой подачи. Влад — детерминированный напарник, без сети и необходимости подключать настоящий геймпад.

- Два учебных заказа без времени и начисления подач.
- Три раунда по 25 секунд или три спокойных раунда без таймера. В спокойном режиме раунд можно закончить раньше.
- Тост = хлеб + сыр; салат = томат + огурец; бутерброд = хлеб + томат. Ошибочный ингредиент не портит заготовку и не штрафует.
- planner: 2400 мс; improv: 1800 мс, вторая передача каждого раунда 3000 мс. Одновременно Влад занимается одним заказом.
- Раунд 2: нарисованный кот на вывеске. Раунд 3: необязательная декоративная лампа. Управление остаётся доступным.
- 7–9 подач — feast, 3–6 — snack, 0–2 — chaos; отдельный skipped при пропуске. Девять подач при завершении дают «Стол на всех» в обоих режимах.
- Меню, сворачивание, потеря фокуса и ручная пауза останавливают и таймер, и напарника. После возвращения нужно явно продолжить. Переключение в спокойный режим доступно на паузе; вернуться к таймеру в этой попытке нельзя.
- Пропуск доступен всегда. Reload начинает только мини-игру заново с обучения, а не всю главу. Сюжетные ответы до неё сохранены.

Для мобильного управления на время кухни сцену гостиной заменяет игровое поле. Заказы, продукты и подача расположены компактно; новелла возвращается после результата. Маленькие экраны допускают вертикальную прокрутку, горизонтального переполнения нет.

Происхождение и промпты — ASSET_CREDITS.md и [ASSET_PROMPTS.md](ASSET_PROMPTS.md). Кухня, продукты, повара и геймпады — оригинальные SVG проекта.

Обновлены реестр глав, движок результатов, типы, reducer, валидатор сохранений, сцена, навигация, режим разработчика, альбом, достижения, PNG-экспорт, стили и команды проверок. ## Сохранения и повторы

Envelope по-прежнему `schemaVersion:1`, контент — `contentVersion:3`. Выпуски 1–2 сначала валидируются в прежних границах, затем меняется только номер версии контента. Сохраняются курсор, ответы, канонические результаты, альбом, настройки, права и пробное прохождение. Новые главы автоматически не открываются. Предыдущий валидный JSON остаётся backup при следующей записи.

Старт третьей копирует канонический финал второй. Валидатор проверяет непрерывность глав, начальные снимки, неизменность унаследованных решений и соответствие served/outcome/mode кухни. Название команды входит в CardRecord третьей, чтобы пробная история не меняла открытку канона.

Пробный повтор третьей не меняет основную историю. Переписывание третьей сохраняет первые две; переписывание второй удаляет основную третью. Права открытия, альбом и достижения сохраняются. Старый код COOP не выдаёт доступ; для третьей назначен новый отдельный код автора.

## Проверки

- TypeScript strict и ESLint — успешно.
- **53 теста** в шести файлах — успешно. Внутри сценарных тестов проверены **288 комбинаций** третьей главы и прежние **432 комбинации** второй.
- Все три реакции на геймпад, три названия команды, две стратегии, четыре исхода ужина, оба ответа после игры и два унаследованных настроения проверены с roundtrip сохранений на промежуточных курсорах.
- Чистая модель кухни: независимые тарелки, задержки напарника, все девять подач в обоих режимах/стратегиях, ошибка без штрафа, повторная подача, скрытый заказ, пауза, раннее завершение и границы результатов.
- **17 браузерных тестов** production-версии — успешно, включая полный вечер, девять подач, PNG, сохранения первых глав, пробный повтор, паузу меню/сворачивания, reload и экран 320×568. Те же тесты проверены для подпапки `/preview-test/` под GitHub Pages.
- Production-сборка подготовлена. Финальная локальная версия оставлена с base `/`; workflow для публикации использует настроенный владельцем VITE_BASE_PATH.

Проверка выполнена в Chromium с мобильной эмуляцией. Реальные iPhone/Safari, Telegram и системная отправка на устройствах ещё требуют отдельного теста. Читательский плейтест длительности главы человеком пока не проводился. Фоновая музыка не подключалась; необязательные тихие звуки действий сохранены.
